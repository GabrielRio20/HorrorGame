# Horror Game Project

## Project Overview
This game follows a detective investigating a murder case in a remote region. Upon arrival, strange and unsettling occurrences quickly escalate, ultimately leading to an unexpected discovery.

## Controls
- **Movement:** WASD + Mouse
- **Interact Item:** E

## How to Run
1. Extract and open the `BuildGame` folder.
2. Navigate to the `Windows` folder.
3. Run `HorrorGame.exe`.

## Horror Direction
This project emphasizes atmospheric horror, slowly building unease as the environment grows increasingly eerie. There are no reliance on jumpscares; instead, the horror relies on disturbing visuals, uncanny atmospheres, and elements of gore.

## Technical Decisions
- **Late-Afternoon Lighting:** Leveraged late-afternoon lighting to establish a bleak, dreary, and uncomfortable atmosphere.
- **Post-Process Volume:** Customized Post-Process Volume settings—adjusting Bloom, Shadow Contrast, Color Temperature, and Film Grain—to match the intended grim visual direction.

## Known Issues
- **Performance Constraints:** Due to time limitations, high-polygon marketplace assets were used without full optimization, which may impact frame rate stability on lower-end systems.

## What I Would Do With More Time
- **Asset Optimization:** Optimize high-poly models, textures, and LODs to significantly improve performance and frame rates.
- **Deeper Horror Mechanics:** Expand interactive elements and refine pacing for a richer horror experience.
- **Audio Design:** Integrate spatialized audio effects and an immersive soundscape to match the visual tone.
